# keycloak-theme-arffornia

Keycloak **login theme for the Arffornia infrastructure realm**, built with
[Keycloakify](https://www.keycloakify.dev/) (React 19, Vite, Tailwind, shadcn components from
`@oussemasahbeni/keycloakify-login-shadcn`). The infra Keycloak protects the admin tools (ArgoCD, Vault,
Longhorn, Adminer). It is **not** used for player login: players sign in on the website with Microsoft.

The theme ships as a small busybox image whose only job is to copy the theme JAR into Keycloak's
`/providers` directory from an initContainer (see `infra/k8s/config/keycloak/values.yaml`). The realm
selects it with `login_theme` in `infra/terraform/main.tf`.

Architecture docs (coming soon): https://arffornia.github.io/docs/

> The theme name is still `keycloak-theme-kube-lab` and the welcome text mentions another project.
> Renaming it requires a matching infra change and is tracked in #18.

## Requirements

- Node.js 22 and npm
- Maven 3 and Java 17+ (only to build the JAR with `make theme`)

## Quickstart

```bash
make install    # npm ci --legacy-peer-deps (runs `keycloakify sync-extensions` as postinstall)
npm run dev     # Vite dev server with mocked Keycloak context
make storybook  # component playground
```

Note: the postinstall currently rewrites `package.json` (`lucide-react` range). Do not commit that change;
see #19.

## Commands

| Command | What it does |
|---|---|
| `make check` | What CI runs: lint + type-check + Vite build |
| `make lint` | ESLint (generated Keycloakify files are ignored) |
| `make build` | `tsc -b && vite build` |
| `make theme` | Build the Keycloak theme JAR into `dist_keycloak/` |
| `npx keycloakify start-keycloak` | Run a local Keycloak with the theme (needs Docker) |

## Layout

- `src/login/` — login theme: `KcPage.tsx` (page router), `pages/`, `components/`, `i18n.ts` (EN/FR texts)
- `src/login/assets/` — logo and images
- `public/keycloak-theme/` — files generated by Keycloakify (do not edit)
- `Dockerfile` — busybox image carrying the JAR

## Configuration

No runtime configuration. Theme name and Keycloak target are defined by the `keycloakify` Vite plugin
(`vite.config.ts`) and `package.json`. Translations live in `src/login/i18n.ts`.

## Release process

Every push to `main` builds the JAR and pushes `ghcr.io/arffornia/keycloak-theme-arffornia:latest` (plus a
`sha-` tag); `v*` tags push semver tags. The infra repository pulls the image in Keycloak's initContainer.
